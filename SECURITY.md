# Security and privacy notes

Online Mod is an early-stage networking mod. It currently uses Minecraft's integrated server and does not operate a project-hosted relay.

- Share your public IP only with people you trust.
- The mod does not currently configure your router or firewall.
- Do not send router passwords, remote-access codes, or other credentials to anyone.
- Only invite players you trust into a world where you have valuable builds or items.
- Stop the host listener when you no longer want incoming connections.
- The host remains responsible for backups and for the permissions granted to players in the world.

Future router integration must require explicit user consent, request only the selected game port, and clean up mappings after the session.
